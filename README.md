# vibelingo
VibeLingo helps users unfamiliar with Gen-Z/Gen-Alpha language understand modern internet slang through context, tone, and situational appropriateness. It features a slang translator, interactive quizzes, and a curated dictionary, supported by streak badges that encourage continuous learning.

It was inspired by the many times millennial and older-generation colleagues expressed confusion when encountering modern internet slang. We noticed that these misunderstandings often created small but frequent communication gaps, and we wanted to build a lighthearted yet useful tool to help bridge that divide.
